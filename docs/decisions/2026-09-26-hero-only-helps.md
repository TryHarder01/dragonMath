# The hero only helps

- **Date:** 2026-09-26
- **Status:** Decided
- **Decided by:** user
- **Revisit when:** Not expected. Only if the user changes the game's premise.

## Decision
The player and Ember are always kind and helpful to eggs, dinos and dragons. No creature is an enemy. Use verbs like warm, find, count, share, tuck in and walk home. Never zap, blast, shoot, fire or chomp. This covers code names, sounds, spoken lines and docs.

It applies going forward. Historical records, meaning older `WORKLOG.md` entries and dated research files, keep their original wording (for example "Egg Zapper"), because the worklog is append-only.

## Why
User request: the main character must be kind and helpful to the eggs, dinos and dragons. No further reason was given.

## Rejected
- **The original Math Blaster framing** (zapping, blasting): replaced by this decision. The game was "Dino Egg Blaster" with an "Egg Zapper" mini-game until the re-theme.
- **Rescue from a villain:** it still brings in an enemy.
